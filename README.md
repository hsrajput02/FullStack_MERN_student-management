# Student Management MERN App

## Introduction

This is a simple full-stack MERN application that allows users to add, view, and delete student records. It demonstrates the integration of React (frontend), Node.js & Express (backend), and MongoDB (database).

---

## Folder Structure


## How to Run

### Backend

```
cd backend
npm install
node server.js
```

### Frontend

```
cd frontend
npm install
npm start
```

## Features

* Add Student
* View Student List
* Delete Student
* Form Validation
* Toggle View Students
